导出索引 ​

根运行时导出 ​

导出说明
digOriginal解开嵌套包装器直到根文件系统。见文件系统。
prefixWrapper把一个带前缀的目录暴露为 Fs 根。见文件系统。
setNeedMigration给设置开关添加迁移确认行为；见设置与界面。
pipe在两个文件系统之间传输文件，自动流式传输。见同步。
readWithSize按大小阈值自动流式读取文件。见同步。
writeWithSize按文件大小自动流式写入值。见同步。
REGRET_ERROR_MESSAGEREGRET_ERROR 的消息，这个哨兵错误表示一个操作被"反悔"而不是失败；同步任务执行器会把这类任务标记为完成而不是失败。见同步。
settingEntry把父设置定义与嵌套设置定义组合起来。见设置与界面。
reactivelyValidate给设置文本输入附加响应式校验。见设置与界面。
generateEditableList生成由临时草稿存储支持的可编辑列表设置定义。见设置与界面。

设置 ​

Settings 是 ctx.settings 处的合并对象。每个设置的说明见用法：设置。

键类型
moduleSourcesArray<string>，模块源 URL
modulesRecord<string, object>，每个模块的设置
moduleAutoUpdateboolean
remoteFsstring，所选后端 ID
syncStrategyArray<GlobStrategy>，有序策略规则
conflictResolverstring，所选冲突解决器 ID
maxFileSizeTogglableValue，最大文件大小（字节）
confirmTasksInSyncboolean
confirmDeleteInAutoSyncboolean
noticeStatusOnMobileboolean
avoidAutoSyncWhenOfflineboolean
startupSyncTogglableValue，延迟（毫秒）
focusSyncTogglableValue，聚焦同步的最小间隔（毫秒）
scheduledSyncTogglableValue，间隔（毫秒）
realtimeSyncTogglableValue，防抖延迟（毫秒）
maxRequestConcurrencyTogglableValue
minRequestIntervalTogglableValue，间隔（毫秒）
realtimeSyncFastModeboolean
asymmetricStorageboolean
customHeadersArray<{ type: 'plaintext' | 'secret'; value: string; key: string }>

TogglableValue 的形状是 { enabled: boolean; value: number }。

其他 Context 成员 ​

这些 Context 成员不常被模块使用。用法模式请阅读源码。

模块管理 ​

成员用途
discoveredModules从发现的模块 ID 到 AugmentedModuleMeta 的 Map。
loadedModules从已加载模块 ID 到模块构造器的 Map。
fetchSources(manual?)从模块源获取模块元数据。manual: true 强制重新获取；false 使用内存缓存。
loadAllModules()加载所有启用且已安装的模块。
loadModule(meta, start?)加载指定模块；可选的第二个参数让它启动。
unloadModule(id)卸载指定模块。
updateModules()查找并下载可用的模块更新。
downloadModule(meta)从 URL 下载单个模块。
installModule(meta, module)从内存中的文件文本安装模块：写入、保存元数据，启用时加载。
deleteModule(id)删除指定的已安装模块。
enableModule(id)启用并加载模块。
disableModule(id)卸载并禁用模块。
updateModuleMeta(meta)更新已存储的模块元数据。
addSettingTab(plugin)把 Sync Engine 设置页加到给定的 Obsidian 插件上。

文件系统与同步 ​

成员用途
createLocalFs()创建包装后的本地文件系统。
createRemoteFs(id?)创建所选的包装后远端文件系统。后端缺失时返回一个 Error。
getRequest()获取组合好的远端请求函数。
getVaultRequest()获取组合好的本地仓库请求函数。
getNamespace(local?, remote?)为可选的本地 / 远端 FS 对创建存储命名空间。未设置后端时返回一个 Error。
initializeSync()为同步创建本地 FS、远端 FS 和记录存储。
getCheckConnection()获取所选后端的连接检查函数。
decideTasks(mapping, factory)对映射中的每个策略桶调用已注册的决策器，返回任务计划。
getConflictResolver()获取所选的 ConflictResolver。
optimizeLocal(input)应用所选的本地 BatchOptimizer。
optimizeRemote(input)应用所选的远端 BatchOptimizer。
reduceTriggers(triggers)把触发器名称归约到最高优先级的条目。
executeSync(trigger, options?)立即执行同步。
requestSync(trigger)排队同步；以 SyncTerminateReason resolve。
remoteFsRegistryMap<string, RemoteFsEntry>。
deciderRegistryMap<string, DeciderEntry>。
conflictResolverRegistryMap<string, ConflictResolverEntry>。

UI 与可观测性 ​

成员用途
executionProgress任务执行的响应式 Progress。
walkProgress远端遍历的响应式 Progress。
syncStage响应式的当前同步阶段。
showProgress()打开进度界面。
hideProgress()隐藏进度界面。
getLogs()返回格式化的当前日志。
exportLogs()把日志导出到仓库文件。
startScheduledSync()启动定时同步。
stopScheduledSync()停止定时同步。

核心与宿主 ​

成员用途
settings合并后的 Settings 对象。
events合并后的 Events 表。
i18n合并后的 Translations 资源表。
appObsidian App 实例。
manifestSync Engine 自己的 Obsidian PluginManifest。
addCommand(cmd)注册 Obsidian 命令并返回它。
removeCommand(command)移除通过 addCommand 注册的命令。
registerEvent(ref)注册 Obsidian EventRef 以便自动清理。
addRibbonIcon(...)添加侧边栏图标并返回元素。
addStatusBarItem()添加并返回状态栏元素。
registerObsidianProtocolHandler(action, handler)注册 obsidian://<action> 处理器；返回注销函数。重复注册同一 action 会替换处理器。
registerView / registerHoverLinkSource / registerExtensions / registerMarkdownPostProcessor / registerMarkdownCodeBlockProcessor / registerBasesView / registerEditorExtension / registerEditorSuggest / registerCliHandler / registerDomEvent与同名 Obsidian Plugin 方法一致。
saveSettings()持久化当前 settings。
on(key, cb)订阅带类型的 SDK 事件。见事件。
dispatch(key, payload?)发布带类型的 SDK 事件。见事件。
isIdle表示同步空闲状态的 SynthKernel Ref<boolean>。
translate从合并的资源中翻译一个键。见设置与界面。
rerenderSettingTab()再次渲染贡献的设置。
refreshSettingTab()低开销的设置页重渲染，让 Obsidian 重新评估每个设置条目的可见性。
