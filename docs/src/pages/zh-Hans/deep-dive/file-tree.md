# 文件树组件

文件树是一个 SolidJS 组件，把同步任务数组可视化，并支持选中 / 取消选中任务。

## 工作方式

为不同的文件夹嵌套层级创建视觉层级（左侧内边距）。

渲染选择框、Obsidian 工具提示、图标和任务路径。

一条通用的路径压缩规则：

- 如果某个文件夹在任务列表中只有一个子项，且文件夹本身不在任务列表中，子项与文件夹合并为一个条目，路径显示为 `<parent-basename> / <child-basename>`。这条规则适用于任意相邻的两段路径，因此连续的嵌套链可以连续合并，只在最浅的公共父级处停止。

选择规则：

- 取消一个删除任务会取消其祖先的删除文件夹任务；选中一个删除文件夹任务会选中其后代删除任务。
- 取消一个文件夹创建任务会取消其后代的创建任务；选中一个创建任务会选中其祖先的创建文件夹任务。
- 这些规则沿所有任务的祖先和后代级联。
- `Move` 任务遵循创建选择规则。
- 只要任何后代移动任务被取消，移动任务就表现为文件夹创建；转换由当前选择状态推导。

行为：只有选中 / 取消选中，没有折叠，没有展开。

全选 / 全不选：

- 这个选项以类似普通树节点的样式渲染，带复选框图标 `folders` 和对应的状态文本 `selectAll` 或 `deselectAll`，位置像树的根节点，在所有任务节点之上。
- 只要任何任务被选中，操作应为 `deselectAll`。只有没有任何任务被选中时，操作才是 `selectAll`。
- 任务被部分选中时，复选框应显示半选状态，否则显示已选 / 未选。

## 实现

1. 预处理：

先从任务路径构建前缀树，然后递归压缩单子项文件夹。展平后的可见树保存任务的祖先与后代链接，用于选择级联。

2. 渲染与选择：

把压缩后的树展平为一维数组，并把节点存入 `Record`。选择状态保存在 Solid store 中；任务转换由该选择状态推导。

UI 只是对展平数组做映射，并按 depth 属性应用 padding-left。
