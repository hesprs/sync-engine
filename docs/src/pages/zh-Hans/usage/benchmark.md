## WebDAV 性能

- **Obsidian 版本**： 1.13.4
- **操作系统**： NixOS 26.11
- **CPU 单核跑分**： 约 1700
- **后端**： 自托管 Nextcloud WebDAV[^12]
- **平均延迟**： 400 ms
- **平均上传速度**： 3 MiB/s
- **平均下载速度**： 5 MiB/s

[^12]: 本地测试中人为加入了连接延迟和带宽限制，模拟中等偏低的网络质量。

| 项目 | Sync Engine | Remotely Save | Nextcloud Sync |
| --- | --- | --- | --- |
| 版本 | 3.0.0 + `webdav` 模块 0.1.7 | 0.5.25 | 0.7.38 |
| 上传 2000 个文件 | **9.43 min** | 16.4 min | 17.95 min |
| 下载 2000 个文件 | 5.87 min | 13.68 min | **5.22 min** |
| 日常模拟<br>(原始库, 10 轮) | 最小: **1.04 s**<br>中位: **1.44 s**<br>最大: **48.56 s** | 最小: 99 s<br>中位: 129 s<br>最大: 326 s | 最小: 1.27 s<br>中位: 2.75 s<br>最大: 60.55 s |
| 日常模拟<br>(副本库, 10 轮) | 最小: 1.06 s<br>中位: **1.72 s**<br>最大: **3.49 s** | 最小: 111 s<br>中位: 117 s<br>最大: 204 s | 最小: **0.4 s**<br>中位: 3.94 s<br>最大: 55.33 s |
| 正确性验证 | 0 个错误 | 0 个错误 | <span style="color: var(--rose); font-weight: bold;">98 个错误</span> |

同步性能方面，Sync Engine 的全量上传和下载明显快于 Remotely Save。在更贴近日常的日常同步测试中，Remotely Save 表现灾难性，Sync Engine 比 Remotely Save 快约 **100 倍**。

Nextcloud Sync 虽然声称针对 Nextcloud 优化，性能上仍明显落后于 Sync Engine。更重要的是，它**未能把 98 个原始文件或变更同步到副本库**，测试过程中出现了大量错误。

## S3 性能

- **Obsidian 版本**： 1.14.5
- **操作系统**： NixOS 26.11
- **CPU 单核跑分**： 约 1700
- **后端**： 自托管 RustFs 1.0.4[^12]
- **平均延迟**： 401.87 ms
- **平均上传速度**： 2.79 MiB/s
- **平均下载速度**： 4.55 MiB/s
- **S3 定价标准**： AWS S3 `us-east-1`，发布于 2026-10-15
