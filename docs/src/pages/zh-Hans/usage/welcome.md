# 欢迎来到 Sync Engine 文档

> 一个同步插件，也是一个平台：用模块扩展它，不需要 fork。

感谢你选择 Sync Engine。我们希望凭借技术创新与持续迭代，成为 Obsidian 生态中最快、最通用的免费同步插件。你每一次使用 Sync Engine，都是对它工程严谨性的认可。

Sync Engine 文档分为三个部分：_用法_、[_开发_](../development/develop-a-module) 和 [_深入解析_](../deep-dive/architecture)，各部分服务于自己的目标：

- _用法_：用所有人都能读懂的语言，讲解 Sync Engine 的使用方式，以及用户最关心的内容（可靠性、安全性与数据隐私）。适合普通用户熟悉和探索 Sync Engine。
- _开发_：详述 Sync Engine 的模块契约与 SDK API。适合希望用自己的模块扩展 Sync Engine 的技术用户。
- _深入解析_：带你了解 Sync Engine 与官方模块的每一个技术细节。适合好奇 Sync Engine 如何实现功能的学习者，以及希望验证 Sync Engine 各项声明的审计者。

当前是*用法*部分，你可能对以下内容感兴趣：

- [为什么选择 Sync Engine](./why-sync-engine)：Sync Engine 与其他同步插件的区别，以及如何开始你的第一次同步。
- [设置](./settings)：Sync Engine 每个设置项的含义。
- [基准测试](./benchmark)：用真实数据看看 Sync Engine 与其他插件的对比。
- [安全](./security)、[权限](./permissions)：Sync Engine 的核心声明，用可验证的证据建立信任。
- [开发模块](../development/develop-a-module)：学习如何开发一个 Sync Engine 模块。

如果发现 Sync Engine 的 bug，请在 [Sync Engine 的 GitHub 仓库](https://github.com/hesprs/sync-engine/issues) 提交 issue。如有疑问，请在 [discussions](https://github.com/hesprs/sync-engine/discussions) 发起讨论。
